## 已检查

- 三张候选可以从同一份基线 PAK 重复生成，输出哈希不变。
- 三份契约均核对了原件哈希、100×100 画布和对应损伤槽位。
- 三档透明边界逐像素保持不变，可见像素仍为 6766、6650、6414。
- 深色眼睛、嘴、轮廓和裂纹没有被重绘；眼白也保持原色。
- 五倍预览中没有早期矩形保护区留下的黄色硬边。
- 砖缝方向和编号牌位置在三档间一致，裂损由原 Alpha 缺口自然递进。
- 合成 PNG、静态预览和完整 PAK 均被 Git 忽略，没有把带原版像素的工作文件收进提交。
- 63 项 Python 自动测试、12 份首批契约注册表检查和八替换 PAK 预演全部通过。
