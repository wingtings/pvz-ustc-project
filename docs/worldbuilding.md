# 世界观与战役设定

## 一句话前提

期末前夜，校园教学沙盘把历年课程、实验报告和截止日期一次性载入，结果生成了会自己往成绩终端走的"错题潮"。玩家要用科豆、实验器材和校园里捡来的怪东西守住五片模拟区域，直到维护程序恢复正常。

这个前提延续了旧日志中"保卫 GPA"的想法，但不把现实中的教师、同学或部门写成敌人。游戏里的微积分、力学和实验报告都是数据异常。它们凶得很具体，也因此适合被打回草稿箱。

## 玩家、向导和对手

玩家是一名参加校园沙盘压力测试的普通学生。名字、年级和专业都不写死，让不同学院的玩家都能代入。

负责引导玩家的是"红帽学长"。他推着一辆装满旧实验器材的手推车，对系统维护略懂，对解释问题很没耐心。他承接疯狂戴夫的商店、选卡和过场功能，不对应任何真实人物。

最终对手是"期末总控机"。它原本负责生成练习题和测试关卡，因为重复载入了整学期的任务，把"完成学习"误判成了"消灭所有学习者"。它会调度课程幻象、投放附加题，并在屋顶模拟区亲自接管战场。

## 战斗中的概念

| 游戏对象 | 改版解释 | 备注 |
| --- | --- | --- |
| 阳光 | 专注值 | 仍以 25 为主要计量单位，减少首版改动量 |
| 大脑 | 成绩终端中的 GPA 数据 | 敌人越过防线后会破坏该行数据 |
| 植物 | 科豆、蝌蝻、校园生物和实验器材 | "植物"可继续作为代码层称呼 |
| 僵尸 | 错题、课程、报告和截止日期的异常投影 | "僵尸"可继续作为代码层称呼 |
| 草坪车 | 自动退课保险 | 每行一次，触发后清除该行异常 |
| 戴夫商店 | 红帽学长的旧货车 | 出售卡槽、升级卡和花园用品 |
| 禅境花园 | 校园温室 | 收集到的单位在这里恢复正常状态 |
| 智慧树 | GPA 树 | 旧版文案已经使用这个称呼，可以保留 |

GPA 只用于关末评级，不作为种植资源。这样玩家不必在"花掉绩点"和"保住绩点"之间理解一套别扭的逻辑。详细算法见[数值与关卡规范](balance-and-levels.md)。

"蝌蝻"在本作中只是一种虚构校园小生物的名字，来自旧日志，不用来概括现实中的科大学生。会发射弹丸的家族统一叫"科豆"，学习蝌蝻、小学习蝌蝻和双学位蝌蝻则保留旧稿的自嘲口吻。

## 五大关

五个世界借用了真实校园的空间印象，但不是校园地图复刻。官方校园地图列出了东、中、西、北、南和高新校区，也收录了郭沫若像、眼镜湖、老校门等地点。关卡可以从这些地点取形，不必声称某个学院就在画面里的那栋楼。[中国科大虚拟校园](https://map.ustc.edu.cn/)

### 第一章：数院草坪

场景取自东区一教与郭沫若广场之间的草坪意象。白天、五行、没有额外地形，玩家先学会生产专注值、按行输出和设置阻挡。

敌人从普通微积分开始，随后加入 B 系列淑芬、撑杆力学和 A 系列淑芬。这里的难点不是数值高，而是让玩家看懂头盔、跨越和前后排关系。

章节获得绿圈科豆、学习蝌蝻、金矿炸弹、出恭墙、三星地雷、寒冰科豆、苕皮卷和双发科豆。1-10 使用传送带，作为第一次综合测验。

### 第二章：物院实验夜

场景是夜间的一教实验区域。未交的大雾实验报告变成墓碑，挡住格子并在大波时生成敌人。夜间不再自然掉落专注值，玩家要依靠小学习蝌蝻建立经济。

这一章把蘑菇机制解释为夜间工作的仪器和临时方案。报告回收箱处理墓碑，大雾实验仪穿透铁门，液氮罐提供全屏控制，大物实验负责清场并留下暂时不能使用的实验坑。

关底是"实验报告总检查"。场上预置大量报告墓碑，玩家需要在清理墓碑和维持火力之间做选择。

### 第三章：化院花园

旧日志中的"花园"在此解释为化院花园与水上区域的混合沙盘。中间两行是实验水槽，普通单位必须放在防水实验台上。章节前半明亮，后半加入夜间水池。

鸭圈流体力学、潜水概率论、低温实验车和四人雪橇小组在这里出现。水槽让横向火力的布置成本上升，低温实验车还会留下冰道，逼玩家准备爆汁烤苕皮或出恭草。

暖气片在本章首次登场。v0.2 只实现原火炬树桩的弹丸加热；v0.4 再加入"敌人靠近后舍不得离开"的减速范围。

### 第四章：计算机雾夜

场景取自西区机房和夜间校园。雾被解释为堆积的日志、告警和网络噪声。充电小台灯能照亮附近区域，机房排风扇暂时清屏，并吹走云端作业。

敌人开始绕过正面防线。地道赶课题从地下到达左侧，跳点证明题跨越单位，DDL 空投直接从屏幕上方拿走一个目标。双端调试科豆和磁盘回收菇分别处理背后与金属装备。

这一章的关底不再靠单纯加血。玩家要同时处理雾、背刺和空投，测试的是选卡覆盖面。

### 第五章：生院温室顶

最后一章位于虚构的屋顶温室。斜坡挡住直线弹丸，所有普通单位需要先放在培养皿上。卷菜科豆、黄油科豆和西瓜科豆使用抛物线攻击，生物安全柜保护周围目标免受空投和投掷物影响。

期末冲刺、扶梯证明题、作业投递车和期末周陆续出现。5-10 中，期末总控机接管温室顶，使用低温球、热浪、空投和召唤。击败它后，沙盘恢复为普通的教学工具，玩家的真实成绩没有被系统自动修改。红帽学长最后才承认，这场测试原本只计划运行五分钟。

## 章节节奏

| 关卡位置 | 任务 |
| --- | --- |
| x-1 至 x-3 | 展示地形或本章的基础经济 |
| x-4 | 引入第一种绕过常规防线的敌人 |
| x-5 | 小游戏或传送带，强制玩家试用新单位 |
| x-6 至 x-8 | 组合两种已学威胁，不额外塞入新规则 |
| x-9 | 长关或高密度关，检验阵型续航 |
| x-10 | 章节考试，使用固定卡组或特殊流程 |

原版五章各十关的结构继续保留。这样可以先替换场景和文案，再逐步调整出怪，不必一开始重写冒险模式索引。

## 反复出现的校园元素

### 绿色圆圈

绿色圆圈是科豆家族的标准弹丸。它最初来自旧日志的一条简短记录，也是现有文案里已经出现的核心梗。视觉上可以使用手绘绿圈或带粉笔边缘的圆形，不直接使用学校标志。

### 淑芬

"淑芬"沿用当前 `LawnStrings.txt` 对"数分"的谐音写法。B 系列淑芬戴普通书套，A 系列淑芬顶铁皮封面，分别对应路障和铁桶槽位。图鉴第一次出现时要写出"数学分析习题投影"，不能假定所有玩家都知道这个称呼。

### 暖气片

暖气片既是弹丸增幅器，也是后续的范围控制单位。科豆的绿色圆圈穿过后变成暖圈，伤害提高。S3 版本中，附近敌人的移动速度降到 80%，因为它们会在热源旁短暂停留。暖气片与寒冰减速不叠乘，只取更强的 50% 减速，避免永久拖延。

### 大雾实验

大雾实验同时承担两个位置。敌方的"大雾实验报告"是读报僵尸槽位，报告损坏后会加速；我方的"大雾实验仪"是大喷菇槽位，能穿过报告和铁门。两者名字接近，但轮廓和图鉴措辞必须明显区分。

### 洗澡

"洗澡"不单独做成一个角色。它进入红帽学长的对话、商店物品和成就文字，例如"热水恢复""忘带校园卡"和"排队时间"。这样能保留旧日志里的生活梗，又不用硬塞进某个战斗机制。

### GPA 树

GPA 树继续替代智慧树。它提供机制提示和校园废话，不宣称树高与真实绩点有任何关系。旧文本中的"突破 40% 的界限"可以作为历史梗保留一次，不再反复使用。

## 语气和边界

项目可以拿课程难度、拖延、报告格式和期末周开玩笑，但不拿具体个人的姓名、外貌、口音或教学事故做素材。行政部门也不直接作为敌人。旧设想中的"JWC 僵尸吃掉一个单位就把 GPA 变成 40%"不进入正式设定，原因有两个：惩罚过重，而且容易把现实部门写成反派。

图鉴口味文字以一两件小事收尾，不讲大道理。科豆会忘带卡，实验仪会担心报告格式，期末周会认真确认自己到底有几门考试。这些细节比泛泛地说"学习很重要"更像这个项目自己的声音。

中国科大 1958 年在北京创办，1970 年迁至合肥，校训精神为"红专并进、理实交融"。这些事实可用于片头或制作人员页面，不要被改写成虚构的战斗口号。[中国科学技术大学章程](https://xxgk.ustc.edu.cn/2017/1026/c13824a658030/page.htm)
