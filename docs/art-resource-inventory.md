# v0.2.1 首批美术资源清单

状态：资源清单已完成，实际替换贴图与游戏内视觉验收留到 v0.5。

盘点日期：2026-08-30

适用基线：PC 版 `1.0.0.1051`，`main.pak` SHA-256 为 `3B5291C6600076AAF1791AE1FB2DBF247290A23E903D1D376413DA17358E049D`。

## 盘点结论

- 当前 PAK 共 2413 个资源。仓库脚本会先核对哈希，再列出或选择性提取文件。
- P01、P02、P04 分别使用独立的植物动画；Z01 与 Z03 共用 `Zombie.reanim.compiled`，书套头通过其中的 `anim_cone` 轨道挂载。
- 选卡和图鉴没有为每个单位保存一张独立大图。`SeedPacket_Larger.png`、`Almanac_PlantCard.png` 和 `Almanac_ZombieCard.png` 是通用框，角色本体仍由动画部件绘制。因此替换角色部件后，选卡和图鉴也要一起复查。
- 四份主动画都能从 PC 压缩格式读成 Raw XML，帧率均为 12 FPS。第三方转换工具只用于这次结构核对，尚未固定版本，也不进入正式构建依赖。
- 原版 PNG 和解码后的动画只保存在被 Git 忽略的 `.work/pak-reference`。仓库只提交清单、工具、测试记录和原创概念稿。

## 共用美术规则

1. 保留原版单位的外轮廓、朝向、落脚点和动作节奏，先做同尺寸部件替换。
2. 科大感来自眼镜、蓝白配色、书本、草稿纸、校园卡和实验器材，不直接贴中国科大校徽，也不让角色影射具体师生。
3. 小字号汉字在最终部件中手工排版。生成式概念图只负责造型方向，不作为游戏贴图直接缩放。
4. 第一轮沿用原版粒子与音效。只有识别物稳定后，才单独替换绿圈、专注值和书套碎屑。
5. 每个替换件必须保留透明边界，并记录原尺寸、锚点、前后层关系和受伤阶段。

## 首批制作顺序

1. 先把 P01 的眼镜合入头部，原尺寸替换并验证眨眼、发射和图鉴。
2. 再制作 P01 的前叶合成书本；若实机遮挡不成立，才回退为独立轨道方案。
3. 用 P04 验证三档受伤贴图替换，不动动画。
4. 用 Z03 的三张书套验证头盔损伤与脱落。
5. 最后处理共享面最广的 Z01，避免一次改动影响所有基础敌人却没有对照图。

这套顺序把“单张静态替换”“分段耐久”“装备层”和“共享骨架”分开验证，便于出现问题时定位回退点。
