# 开发路线图

## 原则

每个版本只跨一层技术难度。文案、静态资源、常量补丁和逻辑钩子分别验收，出问题时才能知道该回退哪一层。

美术采用“保留原版骨架和轮廓，替换或增补局部部件”的路线。文案版不混入贴图改动，资源清单确认后再逐个制作眼镜、书本、书套、徽章和实验器材等科大化部件。

## v0.2：设定和文案基线

状态：进行中。2026-08-30 已完成全量名称、提示和图鉴同步，自动检查与首轮游戏内冒烟测试通过；完整通关和五种场景回归尚未完成。

目标是让游戏里所有可见名称和说明属于同一个世界观，不再出现一半"柯南"、一半原版植物的状态。

交付物：

- 完成 49 个植物槽位和 26 个敌人槽位的名称表。
- 把[植物原型](plants.md)和[敌人原型](zombies.md)的图鉴内容压缩到游戏文本框。
- 统一"专注值""GPA 完整度""科豆""蝌蝻""错题潮"等词。
- 更新选卡、商店、解锁提示、小游戏、禅境花园和通关文本。
- 保持 `LawnStrings.txt` 为 CP936/GBK，完成全量键名与控制标记检查。
- 在五种冒险场景中逐页查看文字，不出现乱码、截断和错误换行。

不在此版本做的事：

- 暖气片范围减速。
- GPA 关末评级。
- DDL 空投扣分。
- 新植物、新敌人或第六章。
- 完整原创贴图和动画。

验收条件是"文案完整且游戏可通关"，不是"设计表已经写完"。

## v0.2.1：资源清单

状态：已完成。2026-08-30 已盘点首批五个槽位的 PAK 部件、动画轨道、受伤阶段和复用范围，并完成 P01 方向概念稿；实际游戏贴图仍属于 v0.5。

这一小版不要求画图，只确定以后要画什么。

每个槽位记录：

- 原动画文件和部件数量。
- 必须替换的角色部件。
- 可暂时复用的粒子与音效。
- 轮廓、主色和识别物。
- 选卡图、图鉴图、受伤阶段和死亡部件。
- 是否需要修改 `reanim.compiled`。

先为 P01 绿圈科豆、P02 学习蝌蝻、P04 出恭墙、Z01 普通微积分和 Z03 B 系列淑芬做清单。这五个单位能覆盖射击、生产、受伤分层、普通敌人和头盔敌人。

绿圈科豆的首批方向已经确定：保留豌豆射手的头部、茎叶和朝向，在独立部件中加入圆框眼镜、托书叶片和一本蓝色《电磁学千题解》。书名文字单独排版，不让生成式图像直接承担小字号汉字；缩到游戏尺寸后至少还要看得出“眼镜、蓝书、科大蓝配色”三个识别点。

## v0.4：三项招牌机制

按下面顺序实现，每次只启用一项。

### 暖气片停留

在暖气片周围指定范围内，敌人移动速度变为 80%。寒冰仍取 50%，多个暖气片不叠加。先用可视化调试标记确认范围，再启用实际减速。

### GPA 完整度

开局设为 100，自动退课保险触发扣 8，关末显示 S、A、B、C。先只做保险事件，胜利和失败流程稳定后再接空投。

### DDL 空投扣分

只有空投成功带走单位并离开屏幕后才扣 4。被击败、被生物安全柜弹开或尚未离场时不扣。同关最多计算四次。

每项机制都要能单独关闭。这样可以区分机制错误和彼此干扰。

绘画工作从这个版本开始，顺序与 v0.2.1 的清单一致。

第一批建议做：

- 绿圈科豆和绿色圆圈。
- 学习蝌蝻与专注值图标。
- 出恭墙的三档受伤外观。
- 普通微积分。
- B 系列淑芬及可脱落书套。

每个角色先做静态部件替换，再调整 reanim。不要同时换角色、动作和粒子，否则崩溃时很难定位缺失引用。

每次视觉提交应同时包含原图尺寸记录、透明边界检查、替换后的静态预览和游戏内截图。修改原版素材得到的工作文件只用于本地构建；公开发行时只提供原创增量或差分补丁，不提交整套解包素材。

## v0.6：五章关卡重排

按[数值与关卡规范](balance-and-levels.md)调整冒险模式解锁、出怪和特殊关。每章先完成 1 至 3 关的垂直切片，再扩到十关。

| 切片 | 必含内容 |
| --- | --- |
| 数院 | 经济、单行攻击、书套头盔 |
| 物院 | 夜间、报告墓碑、穿透 |
| 化院花园 | 水道、防水实验台、低温实验车 |

关卡配置要另存为可审查的数据或补丁，不接受"在 EXE 里改过但没人知道改了哪里"的成品。

## v1.0 候选条件

- 五十关从新存档可以完整通关。
- 49 个植物和 26 个图鉴敌人都有统一名称、图鉴和对应视觉。
- 三项招牌机制可用且可关闭。
- 主要小游戏不会因槽位替换出现软锁。
- 补丁可在匹配哈希的干净基线上重现，也能完整回滚。
- 发行包不包含原版可执行文件、PAK、音乐或整套原贴图。
- README 清楚标出非官方、非商业、需自备合法游戏文件。
- 至少两台不同 Windows 机器完成新存档测试。

## 建议的后续目录

当前只创建 `docs`。开始写补丁和制作素材后，可逐步加入下面的目录，不要提前放空壳。

```text
assets-src/          原创素材源文件，不放原版整包
patches/manifests/   可审查的二进制与资源补丁清单
tools/               构建、校验、同步 LawnStrings 的脚本
tests/checklists/    手工回归清单和测试记录
dist/                本地生成，不提交 Git
```

`dist`、解包后的完整 PAK、存档和临时调试文件应写入 `.gitignore`。
