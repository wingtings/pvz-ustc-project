# 数值与关卡规范

## 数值基线

首个可玩版本尽量沿用原版数值。玩家熟悉的节奏本身就是调试参照，也能把"机制是否有趣"和"数值是否失控"分开处理。

| 项目 | 基线 |
| --- | --- |
| 时间单位 | 游戏逻辑约 100 tick 为 1 秒 |
| 快速卡片冷却 | 7.5 秒 |
| 慢速卡片冷却 | 30 秒 |
| 很慢卡片冷却 | 50 秒 |
| 普通单位耐久 | 300 |
| 绿圈伤害 | 20 |
| 绿圈攻击间隔 | 约 1.43 秒 |
| 普通微积分耐久 | 270 |
| 专注值计量 | 以 25 为一档 |

这里的"约"表示动画和随机初始计时会让肉眼观察值略有浮动。补丁使用游戏内部 tick，图鉴使用玩家能理解的秒数。

## 平衡目标

### 冒险模式

一张新卡第一次出现时，应当在当关明显有用。关卡可以让玩家看到它解决的问题，不强求只有这一种解法。

白天前四关允许单行绿圈科豆独立处理普通微积分。中后期则逐渐要求经济、控制和范围伤害配合。难度来自威胁组合，不靠把所有敌人的耐久统一翻倍。

### 生存与无尽

升级卡和范围输出可以比普通卡更高效，但要占前置格、卡槽或冷却。合肥大炮仍是高上限单位，它的代价是两格黄油科豆、较长建设时间和手动瞄准。

### 校园梗

笑话不能替代战斗信息。名称再奇怪，玩家也应从卡片和图鉴中读出攻击方向、伤害、射程、限制与克制关系。

## 全局机制

### 专注值

专注值替代阳光，只改显示名称，不改基本经济模型。

- 天空掉落 25 点。
- 学习蝌蝻每次产生 25 点。
- 小学习蝌蝻先产生 15 点，成长后产生 25 点。
- 卡片费用继续是 25 的倍数，免费单位除外。

如果以后重画图标，可以把太阳改成台灯光团或绿色圆圈。v0.2 先保留原图标，避免一张图同时影响拾取动画、商店和小游戏。

### GPA 完整度

v0.4 在关卡内部记录一个 0 至 100 的"GPA 完整度"，只用于结算评级。

| 事件 | 变化 |
| --- | --- |
| 开局 | 100 |
| 自动退课保险触发 | -8 |
| DDL 空投成功带走单位并离场 | -4 |
| 敌人进入成绩终端 | 关卡失败，沿用原版逻辑 |

同一关的空投扣分最多计算四次，防止特定出怪表把评级直接清零。评级不奖励通关速度，也不统计剩余专注值，避免逼玩家使用单一速攻打法。

| 完整度 | 评级 |
| --- | --- |
| 90 至 100 | S |
| 75 至 89 | A |
| 60 至 74 | B |
| 1 至 59 | C |

v0.2 没有这套逻辑时，结算仍按普通通关处理。README 和游戏内文案都不能提前宣称已经实现评级。

### 减速、冻结和定身

| 状态 | 效果 | 叠加规则 |
| --- | --- | --- |
| 寒冰 | 移动和攻击速度为 50% | 与暖气片范围不叠乘，取寒冰 |
| 暖气片停留 | 移动速度为 80% | 多个暖气片不重复降低 |
| 液氮冻结 | 完全停止 4 秒 | 结束后保留 10 秒寒冰状态 |
| 黄油定身 | 完全停止 4 秒 | 再次命中只刷新到上限，不无限累积 |

暖圈命中会清除寒冰，与原火炬树桩和寒冰豌豆的关系保持一致。暖气片的范围减速是独立笑点，不应把暖圈改成同时减速和增伤。

### 一击消灭

金矿炸弹、三星地雷、大物实验、爆汁烤苕皮和合肥大炮使用 1800 爆炸伤害。对常规敌人可视为一击消灭，期末周和期末总控机能承受多次。苕皮卷、窝瓜大肚皮和阴暗爬行蝌蝻使用各自槽位的原判定，不额外保证秒杀首领。

## 出怪原则

1. 新敌人首次出现时，不与另一个新敌人同波登场。
2. 旗帜波可以提高总量，但不能同时首次展示新地形和新状态。
3. 单波高耐久敌人增加时，普通敌人数量相应减少。
4. 绕后、空投和跨越单位不在前期连续刷出，给卡片冷却留反应时间。
5. 低温实验车和四人雪橇小组需要冰道，关卡必须保证它们的生成条件能被玩家看懂。
6. 首领战以阶段变化制造压力，不给期末总控机简单乘上十倍耐久。

## 回归矩阵

| 修改类型 | 必测项目 |
| --- | --- |
| 费用和冷却 | 普通选卡、传送带、小游戏、模仿者、升级前置 |
| 伤害和耐久 | 头盔、盾牌、范围伤害、魅惑、首领 |
| 水生和屋顶 | 防水实验台、培养皿、铲除、套壳 |
| 空中和地下 | Wi-Fi 天线、机房排风扇、双端调试科豆、磁盘回收菇 |
| 全屏效果 | 暂停、加速、切回桌面、重开关卡 |
| GPA 评级 | 保险、空投、胜利、失败、保存退出、重玩 |

一个机制只有在对应回归项通过后，才能从"设计中"改成"已实现"。
